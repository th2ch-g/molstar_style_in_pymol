# 実際の Mol* との描画比較

[English](../fidelity.md) · [ガイド](guide.md) · [全ギャラリー](../gallery.md) · [残る差分](../coverage.md)

リボンの残基ごとの曲線・断面、GGX 材質、光源、鎖の配色順、32サンプルの環境遮蔽を
Mol* の実装に合わせました。参照は Mol* の固定コミット
`5b1b54ed03b03936041f514b33b8bb129b774d37` を実際にブラウザーで動かした画像です。
PyMOL は独立した Qt/OpenGL プロセスと native ray で描画しました。CI は使いません。

## 8GNG

同じ mmCIF の A/H/L 鎖を選び、Mol* から取得したカメラをそのまま PyMOL に適用しました。
配色順のため元モデル全体を保持しています。比較対象は cartoon の主鎖で、リガンドの球棒表示や
RCSB の画面 UI は含みません。スクリーンショットから視点を推測した比較ではありません。

| Mol* | PyMOL GPU | PyMOL 専用 ray |
| --- | --- | --- |
| ![Molstar](../gallery/reference-molstar-8gng-color-gpu.png) | ![GPU](../gallery/reference-pymol-8gng-color-gpu.png) | ![ray](../gallery/reference-pymol-8gng-color-ray.png) |

1200 × 900 で、輪郭の重なり（IoU）は GPU **98.15%**、ray **96.70%**。
物体内部の RGB 平均絶対誤差は GPU **1.32/255**、ray **2.30/255** でした。
この条件での実測値であり、全機能の再現率を意味しません。

## 比較条件と結果

座標・二次構造・形状設定・カメラを揃え、正投影、白背景、fog なし、曲線8分割・断面16分割、
光源強度0.6・環境光0.4を使いました。環境遮蔽は32サンプル、半径2^5 Å、bias 0.8、
blur kernel 15です。輪郭平滑化は Mol* の SMAA と PyMOL の方式が異なります。
カメラは各比較例について Mol* から取得しています。

| 比較例 | GPU IoU | GPU RGB 誤差 /255 | ray IoU | ray RGB 誤差 /255 |
| --- | ---: | ---: | ---: | ---: |
| 8GNG、鎖色 | 98.15% | 1.32 | 96.70% | 2.30 |
| 1CRN、matte | 99.25% | 0.67 | 98.36% | 2.14 |
| 1CRN、plastic | 99.25% | 0.95 | 98.34% | 2.57 |
| 1CRN、glossy | 99.13% | 0.75 | 98.12% | 2.18 |
| 1CRN、metallic | 99.25% | 2.17 | 98.30% | 3.08 |
| 1CRN、rounded 断面 | 99.40% | 0.67 | 98.55% | 2.04 |
| 1CRN、円筒ヘリックス・丸い末端 | 99.50% | 0.50 | 98.89% | 2.19 |
| 1BNA、DNA 主鎖 | 99.20% | 0.57 | 98.09% | 1.97 |

RGB のどれかが235未満の画素を物体とし、IoU は両マスクの共通部分/和集合です。
色の誤差は共通部分から輪郭を2ピクセル除いた領域で測定しました。
画像の位置合わせや色の補正は行っていません。白背景と輪郭の差は色の指標から除かれるため、
[全比較画像](../fidelity.md#other-shapes-and-materials)も参照してください。

## 形状と残る差

8GNG の721残基では、曲線座標の最大差は **0.000031 Å**、表面頂点の最大差は **0.000039 Å**。
1CRN の46残基と1BNA の24残基も、丸い断面・円筒ヘリックスを含め0.0001の許容差を満たしました。
これらの構造では PyMOL の H/S/coil 割り当ても一致しています。

表面頂点の比較では、末端円盤を三角形に分けるための中心点を除きます。
PyMOL は Mol* の turn 区分を coil にまとめるため、同じ外形でも内部円盤の有無は異なります。
通常の連続した原子ポリマーでの検証であり、環状・粗視化・欠損部分や核酸塩基の全形状を保証しません。

専用 ray は頂点で、GPU は各フラグメントで材質を計算します。ray は微分による粗さ補正と bump を省略します。
標準 ray、および管理対象外の形状が見える混在シーンでは PyMOL の照明も適用されます。
透明度は三角形を奥から描く方式で、Mol* の OIT とは異なります。その他の効果・表面生成・拡張表示の差は
[対応表](../coverage.md)に記載しています。

密度の専用 ray は、粗い透明断面から画素単位のスカラー場積算へ変更しました。
管理対象の不透明メッシュの深度で遮蔽します。これは本実装の GPU/ray を揃える修正で、
Mol* の密度表示そのものとの画像比較ではありません。管理対象外の形状や透明メッシュを含む場合は
native ray の断面近似を使います。
ギャラリーの Gaussian-volume では GPU/ray の IoU が99.97%、RGB 誤差が0.13/255です。

全82例の GPU/ray ギャラリー、55種の subvisual、273件の数値・復元テスト、Ruff、パッケージビルドが
ローカルで通りました。[比較の再実行手順](../../tests/reference/README.md)と
[条件定義](../../tests/reference/cases.json)を同梱しています。ダウンロードした構造、ブラウザーの bundle、
生の比較 JSON、環境依存のレポートは `.cache/` に置き、Git には追加しません。
